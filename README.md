# ValutaTrade Hub

Консольное приложение для управления валютным портфелем. Позволяет регистрировать пользователей, покупать и продавать валюты, просматривать баланс и получать актуальные курсы валют.

## Технологии

- Python 3.12
- uv — управление зависимостями и окружением
- Ruff — проверка качества кода
- pytest — тестирование
- PrettyTable — форматирование таблиц
- Requests — получение курсов валют
- JSON — хранение данных

## Установка

Требуется Python 3.12 и uv.

```powershell
uv sync
```

## Запуск

```powershell
uv run valutatrade-hub
```

## Команды приложения

| Команда | Назначение |
|---|---|
| `register <имя> <пароль>` | Регистрация |
| `login <имя> <пароль>` | Авторизация |
| `logout` | Выход из аккаунта |
| `show-portfolio` | Просмотр портфеля |
| `buy <валюта> <сумма>` | Покупка валюты |
| `sell <валюта> <сумма>` | Продажа валюты |
| `get-rate <из> <в>` | Получение курса |
| `update-rates` | Обновление курсов |
| `show-rates` | Просмотр доступных курсов |
| `help` | Справка |
| `exit` | Выход |

## Получение курсов

Parser Service получает курсы фиатных валют и криптовалют из внешних источников, объединяет результаты и сохраняет их в `data/rates.json`.

История обновлений хранится в `data/exchange_rates.json`.

Для обновления курсов используется команда:

```text
update-rates
```

## Хранение данных

Данные пользователей, портфелей и валютных курсов сохраняются в JSON-файлах каталога `data/`.

Пароли пользователей хранятся в виде хешей с солью.

## Логирование

Операции покупки и продажи записываются в `logs/actions.log`. Для регистрации событий используется декоратор `log_action`.

## Тестирование

Запуск тестов:

```powershell
uv run pytest -v
```

Проверка качества кода:

```powershell
uv run ruff check .
```
